# 로그인·PWA 검증과 운영 반영 준비

구글 기존 계정 로그인과 보호 화면 접근을 검증한다. PWA 설치·단독 실행·오프라인 동작을 확인한다. 현재 운영 서비스워커의 개인 화면 캐시·오프라인 재노출을 합성 데이터로 재현했으므로, 공개 정적 자산과 고정 오프라인 안내만 저장하고 개인 문서·인증·API·변경 요청을 저장하지 않도록 수정한다. 새 캐시 활성화 시 이 앱의 이전 캐시만 제거한다. 격리 회귀·정확한 커밋 CI·비밀값 없는 운영 이미지·합성 DB 기동 검증·복구 계획을 준비한다. 실제 운영 배포·DNS·DB 변경은 수행하지 않는다. 29sfilm SSH는 보류를 유지한다.

manifest는 public/manifest.json을 단일 원본으로 사용하며 scope를 /로 명시한다. 기존 manifest URL·start_url·암묵적 앱 식별은 바꾸지 않는다. Static의 일 년 캐시 정책을 manifest에 적용하지 않고 서비스워커도 해당 HTTP 캐시를 재검증한다. 실제 운영 반영 전 Chromium 설치 가능성·단독 창·합성 계정·오프라인 안내를 각각 구분한다.
