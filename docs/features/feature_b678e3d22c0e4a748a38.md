# 기준 테스트 복구와 검증 연결

현재 스키마와 기능 계약에 맞춰 오래된 fixture·테스트를 복구한다. 삭제된 박수 필드와 아이콘 없는 배지 때문에 프로필 화면이 실패하는 문제를 수정한다. 일일 인증 조회는 ApplicationController#set_time_zone 및 기존 사용자 설정과 같은 사용자의 현지 날짜 범위를 따른다. 한국 기본값은 Seoul이며 고정 KST로 해외 사용자의 기능을 바꾸지 않는다.

전체 Rails 검사와 백업 도구 검사, 별도 읽기 전용 검토, 정확한 작업 커밋 CI를 확인한다. 운영 DB·env·OAuth·배포는 변경하지 않는다. 기존 동시 요청의 원자적 일일 제한과 시간대 변경 정책은 이번 날짜 범위 수정으로 새로 도입된 문제가 아니며 별도 설계·검증 대상으로 기록한다. 데이터 마이그레이션을 이 수정안에 추가하지 않는다.
