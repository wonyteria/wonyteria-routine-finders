# 오프라인 재시도 버튼 접근성 개선

- 명세번호: `feature_83fe92ad0daf4380be73`
- 리비전: 1
- 상태: 초안
- 대상: `app/views/pwa/offline.html`의 기존 다시 시도 버튼

## 목적

오프라인 화면의 다시 시도 버튼에 접근 가능한 이름과 명시적인 버튼 타입을 제공하여 보조기기 사용성과 HTML 동작의 명확성을 개선한다.

## 사용자 흐름

1. 사용자가 오프라인 화면에서 기존 다시 시도 버튼을 확인한다.
2. 보조기기는 버튼의 접근 가능한 이름을 `인터넷 연결 확인 후 다시 시도`로 인식한다.
3. 사용자가 버튼을 누르면 기존과 동일하게 `window.location.reload()`가 실행된다.
4. 버튼에 표시되는 기존 문구와 디자인은 변경하지 않는다.

## 권한

별도 로그인, 역할, 권한 검사는 없다. 오프라인 화면에 접근할 수 있는 사용자는 누구나 버튼을 사용할 수 있다.

## 예외 및 오류 처리

- 인터넷 연결이 복구되지 않은 경우의 동작은 기존 재시도 동작을 따른다.
- 연결 실패 안내, 재시도 횟수 제한, 오류 메시지 변경은 범위에 포함하지 않는다.
- `window.location.reload()`의 기존 동작은 유지한다.
- 구체적인 브라우저별 접근성 동작은 범위에 포함하지 않는다.

## 데이터

서버 데이터, 운영 DB, 환경변수, DNS, OAuth, 인증 정보 및 워크플로 데이터는 사용하거나 변경하지 않는다. 추가 저장 데이터와 API 변경은 없다.

## 구현 요구사항

기존 다시 시도 버튼에 다음 속성을 추가한다.

- `type="button"`
- `aria-label="인터넷 연결 확인 후 다시 시도"`

다음 항목은 유지한다.

- 기존 버튼 표시 문구
- 기존 디자인 및 스타일
- `window.location.reload()` 동작

## 검증 요구사항

`test/controllers/pwa_controller_test.rb`의 기존 검사를 보존한다. 마지막 클래스 `end` 앞에 다음 회귀 검사를 추가한다.

- 버튼의 접근 가능한 이름이 `인터넷 연결 확인 후 다시 시도`인지 확인
- 버튼의 `type`이 `button`인지 확인
- 기존 버튼 문구가 유지되는지 확인

## 구현 결과 요약

- 기존 다시 시도 버튼 시작 태그에 `type="button"`과 `aria-label="인터넷 연결 확인 후 다시 시도"`를 추가했다.
- 기존 표시 문구, 디자인과 스타일, `window.location.reload()` 동작을 유지했다.
- 오프라인 응답 성공 여부와 버튼의 타입, 접근 가능한 이름, 기존 문구를 확인하는 컨트롤러 회귀 테스트를 추가했다.

## 완료 조건

- 기능명세 초안이 `docs/features/feature_83fe92ad0daf4380be73.md`에 저장된다.
- 기존 다시 시도 버튼에 요구된 두 속성이 반영된다.
- 기존 문구, 디자인, `window.location.reload()` 동작이 유지된다.
- 기존 PWA 컨트롤러 검사가 보존된다.
- 접근 가능한 이름, `type`, 기존 문구에 대한 회귀 검사가 추가된다.
- 변경은 작업 브랜치, 초안 PR, 배포 준비 단계까지만 진행된다.
- main 병합과 운영 배포는 수행하지 않는다.
